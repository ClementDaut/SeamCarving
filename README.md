# SeamCarving
This project implements the Seam Carving algorithm, a content-aware image resizing technique that allows images to be resized while preserving their most important visual content.

The algorithm identifies and removes low-energy seams (paths of pixels with minimal visual importance) from an image. Unlike conventional resizing methods, Seam Carving can adapt the image dimensions while minimizing distortion of salient objects and structures.

This project was developed as part of my studies and explores the main concepts behind content-aware image resizing, including energy maps, seam detection, and iterative seam removal.

The original research paper introducing Seam Carving is also included in this repository:

Avidan, S. & Shamir, A. (2007). Seam Carving for Content-Aware Image Resizing. ACM Transactions on Graphics.
